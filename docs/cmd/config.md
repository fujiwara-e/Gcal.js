## 表示するカレンダの選択
表示するカレンダの選択方法を以下に示す．
1. コマンドラインを開き `config` と入力し `Enter` キーを押す．
2. 表示したいカレンダを選択する(選択しているカレンダにはチェックマークがつく)．
3. `ctrl + s` を押し，表示するカレンダの選択を保存する．

カレンダ一覧・名前・色は初回起動時に取得してDBへ保存し，通常起動では保存済みの情報を使う．以降の一覧・名前・色の更新は，`config` を開いた時だけ行う．Google Calendar側でカレンダを追加したり名前・色を変更した場合は，`config` を開くことで反映される．`sync` は予定（タスク機能ONの場合はタスクも）を同期し，カレンダ一覧・色は再取得しない．

既存カレンダの選択状態は保持され，新しく見つかったカレンダは未選択になる．表示したい場合はチェックして保存する．Google側で一覧から消えたカレンダは表示対象から外れるが，保存済みの予定は削除しない．一覧・名前・色は `config` を開いた時に更新されるため，`Escape` で閉じても反映される．チェックの変更は `Ctrl+S` で保存するまで反映されない．

一覧の取得に失敗した場合は既存キャッシュを保持し，TUI内のログに通知する．全カレンダを未選択にした場合や取得した一覧が0件の場合も，次回起動で自動的に一覧を再取得しない．

## タスク機能のON/OFF

タスク機能はデフォルトOFF．`config` コマンドは表示カレンダの選択用で，タスク機能は `setting.json` の最上位の `tasksEnabled` で切り替える．

```json
{
  "tasksEnabled": true
}
```

既存のキー設定などを残したまま，上記の項目を追加・変更してアプリを再起動する．`true` の場合だけ有効になり，`false` または未指定の場合はタスクを同期・表示せず，タスクの追加メニューも表示しない．保存済みタスクはDBに保持される．

初めてONにする際はGoogle Tasks APIを有効化し，Tasks権限のない既存の `token.json` があれば削除して再認証する．
