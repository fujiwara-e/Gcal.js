## 予定の編集
予定の編集方法を以下に示す．
1. 編集したい予定を選択する．その後 `イベントを編集` を選択する．
2. 編集先のカレンダを選択する．(誤って他のカレンダに追加してしまったものを編集する際に有効)
3. 予定の詳細を入力する (エディタを vim に設定している場合は `:wq` で保存して終了)．
4. `ctrl + s` を押し，イベントを Google Calendar に反映させる．

同じカレンダ内では元の予定を更新する．別のカレンダへの移動では，移動先への登録が成功してから元の予定を削除する．更新や登録に失敗した場合，元の予定を削除せずにエラーを表示する．

移動先への登録後に元の予定の削除を確認できなかった場合は，移動先の予定を保持して警告を表示する．予定が両方のカレンダに残っている可能性があるため，再操作する前に両方を確認する．
